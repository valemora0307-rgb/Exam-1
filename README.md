# Mi Primer Repositorio Web

Un proyecto sencillo para practicar HTML, CSS y JavaScript.

## Que incluye

- `index.html`: la estructura de la pagina.
- `styles.css`: los colores, espacios y estilos.
- `script.js`: una interaccion pequena con JavaScript.

## Como usarlo

1. Abre la carpeta del proyecto.
2. Abre `index.html` en tu navegador.
3. Cambia textos, colores o tareas para practicar.

## Como abrirlo en Visual Studio Code

1. Abre Visual Studio Code.
2. Elige `File > Open Folder`.
3. Selecciona esta carpeta del proyecto.
4. Abre `index.html`.
5. Puedes usar la extension Live Server para verlo en el navegador.

## Ideas para practicar

- Cambia el titulo de la pagina.
- Agrega una nueva tarjeta.
- Modifica los colores en `styles.css`.
- Haz que el boton muestre otro mensaje.
- Agrega mas tareas a la lista.

## Conceptos que puedes aprender aqui

- Etiquetas basicas de HTML.
- Como conectar CSS y JavaScript a una pagina.
- Como cambiar estilos.
- Como escuchar clics con JavaScript.
